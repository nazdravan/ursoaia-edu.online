Dacă vrei să... Alege
Construiești site-uri web Web

Lucrezi cu date și automatizări Python

Te pregătești pentru proiecte cu microcontrollere Python (sintaxa se transferă la MicroPython pe ESP32)

Cursurile nu se exclud

Web, Python și Design Grafic se completează — mulți programatori profesioniști le folosesc pe toate. Începe cu cel care te motivează mai mult, apoi adaugă-le pe celelalte. Combinația Design Grafic + Web este cea mai directă: desenezi interfața, apoi o construiești în HTML și CSS.

De ce aceste cursuri?¶

  • Gratuite și open-source — toate lecțiile sunt aici, fără înregistrare
  • În limba română — explicații clare, fără jargon netradus
  • Cu exemple concrete — nume și contexte familiare (Cluj, Chișinău, București)
  • Cu feedback imediat — fiecare lecție are exerciții și soluții
  • Cu mini-proiecte — construiești ceva concret la final de fiecare lecție

Proiecte hardware¶

Dacă ai deja bazele de programare și vrei să treci la electronică, vezi secțiunea Proiecte — Arduino, ESP32, LoPy și Raspberry Pi cu scheme complete și cod sursă.
